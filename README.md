# No Black Boxes links

A small, static link page for No Black Boxes, published with GitHub Pages.

## Preview locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Publish

Push the `main` branch to GitHub. The Pages workflow deploys the site to:

<https://noblackboxes.github.io/our-links/>

The first deployment may require selecting **GitHub Actions** under
**Settings → Pages → Build and deployment → Source**.

The downloadable QR code in `assets/qr-code.svg` points to the same URL.
